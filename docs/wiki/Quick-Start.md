# 快速开始

## 1. 安装

1. 打开 [Releases](https://github.com/AS13379/debate-studio/releases/latest)。
2. 下载文件名以 `arm64.dmg` 结尾的安装包。
3. 打开 DMG，将 **Debate Studio** 拖入“应用程序”。
4. 从“应用程序”中打开 Debate Studio。

当前版本面向 Apple Silicon Mac。社区构建可能没有 Apple Developer ID 公证；如果 macOS 阻止首次打开，请先确认文件来自本仓库，然后在“系统设置 → 隐私与安全性”中允许打开。

## 2. 第一次启动

首次引导包括五步：

1. 了解本地数据和凭据边界。
2. 选择模型服务商并保存 API Key。
3. 发送最小请求测试连接。
4. 创建默认 ModelProfile 和模型策略。
5. 创建第一场示例辩论。

你可以随时跳过。跳过后仍可使用完全离线的 Mock 模型体验完整流程。

## 3. 最快体验方式

1. 在首页点击“创建 Mock 示例辩论”。
2. 打开刚创建的辩论。
3. 点击“启动”。
4. 观察阶段进度、流式发言和角色切换。
5. 完成后查看裁判评分和赛后复盘。

Mock 不访问真实网络，不读取系统凭据，也不会消耗任何模型额度。

## 4. 配置真实模型

进入“设置 → 模型与平台”：

1. 选择官方平台预设。
2. 检查 Base URL。
3. 输入 API Key 并保存。
4. 等待自动连接测试。
5. 从模型预设列表选择 Model ID，或使用自定义 ID。
6. 保存 ModelProfile。

API Key 只在保存时短暂经过 Renderer，之后由主进程安全存储。界面不会再次返回明文。

## 5. 新建第一场真实辩论

1. 打开“新建辩论”。
2. 保持“AI 自动规划”或切换到手动模式。
3. 输入一个无需联网也能理解的简单辩题。
4. 为正方、反方、主持人和可选裁判选择模型。
5. 查看启动前校验结果。
6. 创建并启动。

首次测试建议：

- 自由辩论轮数设为 1。
- 使用普通或快速模型。
- 正方、反方和主持人可以先用同一个 ModelProfile。
- 研究深度选择“低”或“标准”。

## 6. 应用更新

从 v0.7.0 起，macOS 客户端通过 Sparkle 检查并安装项目签名更新。更新只替换应用程序，不会覆盖本地数据库、API Key、模型配置或历史辩论。
