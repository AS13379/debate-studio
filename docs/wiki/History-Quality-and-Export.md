# 历史、评分与导出

## 历史管理

首页可以：

- 搜索辩题或自定义名称
- 按更新时间排序
- 收藏
- 添加标签
- 归档和恢复
- 软删除和从回收站恢复
- 批量收藏、归档、删除或导出

软删除不会立即清除 Turn、研究资料和证据，也不会影响 Provider、ModelProfile 或 API Key。

## 详情页

详情页按需加载：

- 基本信息
- 模型配置摘要
- 研究状态
- 证据数量
- Turn 数量
- 最终裁决
- 评分和复盘
- 导出历史

长正文默认折叠或分页，不会一次加载全部历史。

## 质量分析

裁判公开评分包含：

- 逻辑完整性
- 证据质量
- 反驳有效性
- 事实准确性
- 论证深度
- 表达清晰度

每项 0–10 分并附简短理由。质量页面还显示平均评分、趋势、常见不足、证据数量、模型和 Prompt 版本表现。

赛后复盘包含最佳论点、最佳反驳、错失机会、证据分析与改进建议，不保存隐藏思维链。

## 导出

支持：

- Markdown
- 单文件 HTML

导出包含辩题、模型摘要、公共研究、公开证据、按时间排序的发言、裁决、评分和复盘。

“包含私有研究”默认关闭。开启前应用会明确提示，并在导出元数据中记录选择。

桌面端导出时先选择保存位置；任务完成后会显示结果。LAN Web 通过安全下载接口返回文件，不暴露 Mac 上的绝对路径。

## 成本统计

只有服务商返回 Token 用量时才进行统计。若没有 Token 或没有定价，界面显示“未知”或“未配置价格”，不会猜测。
