# Debate Studio

Debate Studio 是一个运行在 macOS 上的本地 AI 辩论、研究与证据工作台。它不是聊天记录外壳，而是一套可以长期使用的完整流程：

```text
辩题规划
→ 主持人建立公共方向
→ 正反方独立研究
→ 整理论点与证据
→ 正式辩论
→ 裁判评分
→ 赛后复盘
→ 本地归档与导出
```

## 它能做什么

### 1. 用 AI 规划一场辩论

只输入一个辩题，Debate Planner 可以生成背景说明、正反方立场、关键问题、研究方向与证据建议。生成结果必须由用户确认后才会写入辩论 Session，也可以随时编辑或完全手动创建。

### 2. 让多个模型承担不同任务

主持人、正方、反方和裁判可以使用相同或不同模型。模型策略还能把辩题规划、研究、搜索摘要、正式论证、反驳、裁判和视觉分析分别交给更合适的模型。

### 3. 让双方真正研究，而不是凭空争论

主持人可以整理公共资源方向；正反方在相互隔离的私有空间中搜索、阅读网页、保存资料评价、研究笔记和暂定主张。私有资料只有在主动发布后才会进入公开证据桌。

### 4. 观察并控制完整运行过程

应用显示当前阶段、正在工作的角色、流式正文、思考活动和工具调用。你可以暂停、继续、停止、跳过阶段或重试失败轮次；已经生成的部分文本不会因失败而丢失。

### 5. 得到结构化裁判与复盘

裁判会从逻辑完整性、证据质量、反驳有效性、事实准确性、论证深度和表达清晰度进行公开评分。赛后复盘会总结最佳论点、有效反驳、错失机会和改进方向，不保存隐藏思维链。

### 6. 长期保存和整理

所有业务数据进入本机 SQLite。历史页面支持搜索、收藏、标签、归档、软删除与恢复；可以导出 Markdown 或单文件 HTML，也可以备份和恢复数据库。

### 7. 从手机继续操作

局域网 Web 控制台默认关闭。你可以在可信家庭网络中主动开启，用手机或平板创建辩论、查看流式过程、控制运行、阅读历史和下载导出。

## 设计原则

- **本地优先**：不提供账号、云同步或遥测。
- **凭据不出主进程**：Renderer、SQLite、日志和导出都拿不到 API Key。
- **研究空间隔离**：一方模型不能读取另一方私有研究。
- **增量持久化**：运行、Turn、事件和研究结果持续保存，崩溃后仍可恢复。
- **显式状态机**：每个阶段和命令都有明确合法边界，避免后台悄悄改变状态。
- **统一适配层**：Mock 与真实模型共用 ModelAdapter、TurnRunner 和 SessionRunner。
- **安全更新**：Sparkle 2 使用项目 EdDSA 发布签名校验更新包，只替换应用本体。
