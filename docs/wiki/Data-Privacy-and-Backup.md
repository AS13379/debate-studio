# 数据、隐私与备份

## 本地数据

Debate Studio 的业务数据默认位于：

```text
~/Library/Application Support/debate-studio/
```

这里可能包含数据库、加密凭据文件、资源、导出、日志与备份。升级应用只替换程序文件，不覆盖该目录。

## API Key

API Key：

- 只在保存时作为一次性输入进入主进程
- 使用 Electron 安全存储能力保护
- 不写入 SQLite
- 不返回 Renderer 或 LAN Web
- 不进入日志、错误记录、导出和诊断报告

SQLite 只保存与连接相关的非敏感配置。界面只显示“未配置”“已保存”“测试成功”或“测试失败”。

## 日志与错误

结构化日志自动脱敏，禁止记录 Authorization Header、credentialRef、私有研究和完整网页正文。

诊断报告可以包含应用版本、系统信息、最近错误、运行阶段和测试状态，但不包含用户正文全文或敏感凭据。

## 数据库备份

在“设置 → 数据管理”中可以：

- 创建手动备份
- 查看备份
- 恢复备份

数据库迁移前会自动备份；失败时可以恢复。恢复会先停止正在运行的 Session，并要求二次确认。

备份主要覆盖 SQLite 业务数据，不导出明文 API Key。

## 删除与导出

- 历史删除默认为软删除，可以恢复。
- 导出默认排除双方私有研究。
- 删除 Provider 不等于删除 API Key，除非用户明确选择同时删除凭据。
- 删除应用本体不会自动删除 userData。

## 反馈问题时

不要公开提交：

- API Key 或 Authorization
- credentialRef
- SQLite 数据库
- 加密凭据文件
- 真实日志和诊断包
- 私人辩题、研究资料或导出
- 含有个人信息的截图

推荐先用 Mock 示例复现，并只提供脱敏后的错误代码和必要界面。
