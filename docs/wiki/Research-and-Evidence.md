# 研究与证据

## 四种可见性

- `public`：所有角色可见
- `affirmative-private`：仅正方研究上下文可见
- `negative-private`：仅反方研究上下文可见
- `moderator-private`：仅主持人研究上下文可见

用户可以在界面查看双方研究区，但系统不会把一方私有资料自动注入另一方模型。

## 研究流程

1. 主持人建立公共资源方向。
2. 正方制定计划并独立研究。
3. 反方制定计划并独立研究。
4. 双方保存来源评价、研究笔记和暂定主张。
5. 双方选择性地发布公开证据。
6. 进入正式辩论并引用证据编号。

支持的工具包括：

- 搜索网页
- 读取网页正文
- 保存研究笔记
- 保存暂定主张
- 发布证据
- 完成研究

研究工具有防止重复搜索和无限循环的预算规则。预算的目标是控制无效等待，不是限制费用；有效新来源和必要总结会被优先保留。

## 人工资料

研究区可以添加：

- 粘贴文本
- 网页 URL、人工标题和摘要
- 图片
- PDF

网页不会自动登录；本地地址、`file://` 和非 HTTP/HTTPS 协议会被拒绝。图片和 PDF 只返回安全资产 ID 与元数据，不向 Web 暴露本机路径。

## 公开证据桌

私有来源发布后会获得稳定编号：

- 正方：`A-S1`
- 反方：`B-S1`
- 主持人：`M-S1`

原私有记录继续保留。证据状态包括：

- 未核验
- 有支持
- 有争议
- 已过时
- 无法访问
- 有误导性
- 已拒绝

每次状态变更都会新增历史记录，不覆盖旧状态。模型引用不存在的编号时会被标记。

## 来源评价

读取来源后可记录：

- 来源用途与辩题关系
- 支持或反对的主张
- 来源类型
- 发布时间
- 可信度
- 局限
- 是否建议发布

仅看到搜索摘要时，应明确标记为“尚未核验”，不要把摘要冒充已读正文。
