# 常见问题

## 首次打开被 macOS 阻止

确认 DMG 来自本仓库 Release，然后在“系统设置 → 隐私与安全性”中允许打开。不要从不明镜像下载，也不要把 API Key 发给任何人。

## 连接测试失败

依次检查：

1. 平台预设和 Base URL 是否匹配。
2. API Key 是否保存成功。
3. 账户是否有余额或可用额度。
4. Model ID 是否存在并有权限。
5. 网络是否能访问服务商。

401 通常与凭据有关，429 常见于限流或额度，404 常见于 URL 或模型名称。技术详情会脱敏后显示。

## 请求长时间没有正文

思考模型可能先返回 reasoning。页面会显示等待时间和思考活动。你可以暂停、停止或跳过当前阶段。

如果服务商以 `finish_reason=length` 结束且只有思考内容，说明输出额度在生成正文前耗尽。请缩短任务、换用普通模型，或使用平台建议的输出范围。

## 研究显示“工具预算已用完”

工具预算用于阻止重复搜索和无限循环，不是费用上限。系统会要求模型利用已有资料总结。如果资料明显不足，可以选择更高研究预设、重试失败阶段或补充人工资料。

## 裁判说没有收到双方内容

先查看裁决 Turn 与赛后分析：

- 如果赛后分析正常但裁决异常，可能是裁决请求上下文未完整构造。
- 不要删除原 Turn；使用“用当前 Prompt 重新评分”或重试裁判阶段。
- 导出或反馈时提供脱敏后的错误代码，不提交整库。

## 更新后数据会消失吗

不会。Sparkle 更新只替换 App，SQLite、API Key、模型配置和历史位于 userData 目录。仍建议在重大升级前创建数据库备份。

## 局域网页面打不开

检查：

- 桌面端服务是否开启；
- 是否选择“开放局域网”；
- 手机和 Mac 是否在同一网络；
- URL 中 IP 与端口是否仍然有效；
- Mac 是否刚从休眠中恢复。

公共 Wi‑Fi 中请关闭局域网访问。

## 如何安全反馈 Bug

1. 尽量用 Mock 数据复现。
2. 截图前遮盖私人辩题和资料。
3. 复制应用生成的脱敏错误详情。
4. 不上传数据库、凭据库或完整日志。
5. 在 [Issues](https://github.com/AS13379/debate-studio/issues) 描述操作步骤、期望结果和实际结果。
