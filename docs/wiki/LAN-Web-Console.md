# 局域网 Web 控制台

局域网 Web 用于你离开 Mac 后，在同一可信网络中用手机、平板或另一台电脑继续操作 Debate Studio。它不是公网服务或多人协作平台。

## 开启

1. 在桌面端进入“设置 → 局域网访问”。
2. 选择“仅本机”或“开放局域网”。
3. 开启服务。
4. 局域网模式下复制显示的 URL，或用手机扫描二维码。

默认端口为 `27180`。如果端口冲突，应用会显示中文错误，不会在没有用户选择时静默切换到随机端口。

## 两种访问范围

- **仅本机**：只允许当前 Mac 的浏览器访问，适合本地预览。
- **开放局域网**：同一局域网设备可直接打开 URL，不需要登录或配对。

开放模式适用于个人可信家庭网络。不要在咖啡店、酒店、机场等公共 Wi‑Fi 中开启。

## Web 端能力

- 查看、搜索历史辩论
- 新建辩论和 AI 规划
- 启动、暂停、继续和停止
- 查看实时流式正文与可折叠思考活动
- 查看研究、搜索结果、来源与公开证据
- 查看评分、复盘和成本
- 上传图片或 PDF
- 生成并下载 Markdown/HTML 导出

手机端使用单列卡片和底部导航。手动向上阅读时会暂停自动跟随，回到底部后恢复。

## 安全边界

Web 端：

- 不返回 API Key 或 credentialRef
- 不直接访问 SQLite
- 不返回本机绝对路径
- 不读取未授权文件
- 不暴露桌面 Renderer 源码

服务保留 Host/Origin 校验、请求体限制、上传检查和基础限流。关闭应用或关闭局域网访问后，Web 页面会保留当前画面并提示主机离线。
